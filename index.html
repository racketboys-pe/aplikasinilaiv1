Cara Setup:
1. Buka Google Sheet → Extensions → Apps Script
2. Paste kode dari file GAS_Backend_PJOK.js
3. Run setupAwalDatabase() sekali
4. Deploy → New Deployment → Web App
   • Execute as: Me | Access: Anyone
5. Copy URL → paste di kolom atas → Simpan & Tes
6. Jika update kode GAS: Manage Deployments → Edit → New version
